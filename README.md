# openfunds plugins and Agent Skills

Practical tools, validators and AI Agent Skills published by [openfunds](https://www.openfunds.org) and its Active Members to support the implementation of the openfunds standard.

## Install in Claude Code / Cowork

Add this repository as a plugin marketplace in Claude Code:

```text
/plugin marketplace add openfunds-org/agent-skills
```

Then install the `openfunds-tools` plugin:

```text
/plugin install openfunds-tools@openfunds-plugins
```

## Provider-neutral ZIP installation (OpenCode, Codex, and other Agent Skills hosts)

Each GitHub Release publishes standalone `<skill-name>.zip` archives (for example, `openfunds-terms-and-conditions.zip`). Each archive contains the complete Agent Skill folder (`SKILL.md`, `scripts/`, `reference/`, `assets/`, `tests/`, `LICENSE` and `NOTICE`) without any host-specific wrapper.

Download the archive from the **Releases** page and install or upload the unpacked folder according to the instructions for your Agent Skills-compatible host.

## Available plugins and skills

### `openfunds-tools`

- **`openfunds-terms-and-conditions` (`v2.0.1`)** — Developed by [Titanbay](https://www.titanbay.com) in collaboration with the openfunds Private Markets Working Group. Reads a fund's legally binding prospectus, offering memorandum or supplement (PDF or DOCX) and compiles subscription and redemption terms into a draft openfunds v2.14.0 OFTC Excel workbook (`Transmission_view`, `Grouped_view`, `Evidence`, `Candidate_ledger`, `Open_questions` and `Run_metadata`) plus a Markdown review report.

## Adding a new skill

This repository is structured so openfunds and Active Members can add further skills (such as validators, checkers or calendar generators) with minimal effort:

```bash
python3 scripts/scaffold_skill.py --name openfunds-<new-skill> --description "..."
```
